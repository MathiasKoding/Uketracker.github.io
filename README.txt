STUDIETRACKER V8 – FULL PAKKE

Denne versjonen er laget for at du kan SLETTE ALT i GitHub-repositoryet
og laste opp hele pakken på nytt.

MÅ LASTES OPP:
- index.html
- sw.js
- manifest.webmanifest
- ntnu-logo.png

VALGFRITT:
- README.txt

FUNKSJONER I V8:
- Marin, Matte, ITGK og Mekanikk
- 10 timer mål per fag
- 40 timer totalt per uke
- 60 min arbeid / 15 min pause
- Dagens effektive arbeidstid i HH:MM:SS
- Pauser teller ikke
- Arbeidstid legges automatisk til valgt fag
- Manuell registrering med timer + minutter
- Redigering av total tid per fag
- Automatisk ukesnullstilling
- Import av Apple/iCloud-kalender via .ics
- Ukevisning av kalenderhendelser
- NTNU-logo som bakgrunn/vannmerke
- Lokal lagring på enheten

SLIK OPPDATERER DU GITHUB:
1. Slett alle gamle filer i repositoryet.
2. Last opp ALLE filene fra denne v8-mappen.
3. Commit direkte til main.
4. Vent til GitHub Pages er ferdig.
5. Lukk Studietracker helt på iPhone/iPad.
6. Åpne den igjen fra hjemskjermen.

VIKTIG:
Når du sletter filer på GitHub, slettes ikke nødvendigvis studietidene dine.
De ligger lokalt i nettleseren/PWA-en på enheten, så lenge nettsideadressen er den samme
og du ikke sletter nettleserdata/nettstedsdata.

Hvis du vil være ekstra trygg før større endringer, skriv ned eller ta skjermbilde av
ukestidene dine.
