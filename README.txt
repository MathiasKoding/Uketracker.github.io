STUDIETRACKER V11 – AUTOMATISK REGISTRERING

Nytt:
- Når du trykker Pause/Stop på 60-minutterstimeren, registreres tiden umiddelbart på valgt fag.
- Stopper du etter f.eks. 34:00, legges 34:00 automatisk til faget og ukesmålet.
- Når 60 minutter fullføres, registreres hele arbeidsblokken automatisk.
- 15-minutters pause registreres aldri som arbeid.
- En liten tekst under timeren bekrefter siste automatiske registrering.
- Robust lukking/gjenåpning fra v10 er beholdt.
- Ingen nye store knapper.

GitHub:
Hvis du har v10, erstatt bare index.html og sw.js.
Commit til main, vent på GitHub Pages, lukk appen helt og åpne igjen.
